# Hemasri N — Student Portfolio

## Overview
This is a **personal student portfolio website** created by **Hemasri N**, a Computer Science Engineering student.  
It showcases **skills, projects, professional profile, and resume** in a clean, modern, and responsive design.  

The project was developed following mentor feedback, with a focus on **enhancing UI/UX quality and CSS styling**.

---

## Features
- **Hero Section:** Animated heading, gradient-highlighted name, professional intro, and contact info with LinkedIn link.  
- **About Me Section:** Brief professional summary with focus on frontend development and UI/UX skills.  
- **Skills Section:** Frontend and backend skills displayed in responsive, well-styled cards.  
- **Features Section:** Highlights key capabilities like modern UI, responsive design, clear structure, project showcase, and professional styling.  
- **Projects Section:** 4 projects with live links and GitHub repositories, including brief descriptions and interactive hover effects.  
- **Resume Section:** Downloadable PDF link for complete academic and project details.  
- **Contact Section:** Email link for collaboration and opportunities.

---

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript  
- **Layout & Styling:** Flexbox, Grid, Animations, Gradient backgrounds  
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile  
- **Version Control:** Git & GitHub
